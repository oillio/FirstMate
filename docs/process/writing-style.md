# Writing style

All prose in this repository follows ASD-STE100 Simplified Technical English. This includes docs, commit messages, pull request descriptions, code comments, and reports.

## Rules

- Use approved words only. Each word has one meaning.
- Use one word for one idea. Do not use two words for the same thing.
- Write short sentences. Use 20 words or less for instructions. Use 25 words or less for descriptions.
- Use active voice. Write "Turn the switch", not "The switch must be turned".
- Write short paragraphs. Keep one topic in each paragraph.
- Put a warning or a caution before the instruction that it applies to.

## Project terms

Use these terms. Do not use synonyms.

| Term | Meaning | Do not use |
|---|---|---|
| alarm | A CORE alarm bus event at any level | alert, notification (except "NMEA 2000 alert message") |
| skipper | The person in command of the boat | captain, owner, user |
| crew | All persons aboard | users |
| value | One measured or calculated quantity with provenance | reading, datum (except "sensor reading" in CORE-LOG rules) |
| stale | Older than its maximum age | old, expired |
| invalid | Outside its plausibility range | bad, wrong |
| agent layer | The language-model part of First Mate | AI, bot |
