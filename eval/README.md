# Evals

Eval suites for each subsystem, and the seeded-defect catalogue.

- `seeded-defects/`: known field defects as tests.
- Frozen eval suites with floors come with each Agent Specification (candidate discipline, not adopted).

Recorded bus data is the main test input (CORE-REC-02). The raw files stay outside git. Test fixtures cut from them go here, small and labelled with their source file.
